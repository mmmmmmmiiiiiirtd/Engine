# 🚀 Micro Text Engine (MTE)

Легковесный 2D-игровой движок на Python поверх **pygame-ce**, работающий как кастомная виртуальная машина. Движок построчно считывает код игры из простых текстовых файлов и выполняет их через `exec()` в изолированном контексте. 

Идеально подходит для геймификации обучения базовому синтаксису Python и проведения хакатонов. **Учебники больше не нужны — синтаксис учится в бою!**

---

## 📖 Справочник по функциям (API движка)

### ⏱ Время и Управление кадрами
* `time` — переменная, хранит текущее время раунда в миллисекундах (начинается строго с `0` при старте раунда или рестарте).
* `wait(ms)` — приостановить выполнение кода в файле скрипта на `ms` миллисекунд (при этом экран продолжает плавно рендериться и FPS окна не фризится!).
* `restart()` — полностью сбросить игру, стереть все объекты из памяти и начать раунд заново с 0 мс.

### 🎮 Ввод (Клавиатура)
* `key_pressed(char)` — возвращает `True`, если клавиша зажата, и `False`, если отпущена. Подходит для плавного перемещения.
* *Доступные клавиши:* `'w'`, `'a'`, `'s'`, `'d'`, `'space'`, `'up'`, `'down'`, `'left'`, `'right'`.

### 📦 Игровые объекты (Боксы)
* `creat_box(name, x, y, width, height, color, type)` — создать прямоугольный объект. Параметр `type` может быть `"static"` или `"dynamic"`.
* `deleted_box(name)` — удалить объект по его уникальному имени.
* `exists_box(name)` — проверить, существует ли объект на сцене (возвращает `True/False`).
* `move(name, x, y)` — сместить объект на дельту координат (включает физику столкновений и увлечения).
* `move_to(name, x, y)` — мгновенно телепортировать объект в точные координаты (работает без просчета физики!).
* `change_size(name, dx, dy)` — изменить текущий размер объекта на указанную дельту (работает без просчета физики!).
* `change_size_to(name, width, height)` — установить объекту точные ширину и высоту (работает без просчета физики!).
* `check_collision(name1, name2)` — проверить столкновение (пересечение) двух объектов (возвращает `True/False`).
* `get_x(name)`, `get_y(name)`, `get_width(name)`, `get_height(name)` — получить текущие параметры геометрии бокса.

### 🔊 Текст и Звуки
* `creat_text(name, message, x, y, size, color)` — создать и вывести текстовую надпись на экран (для счета, таймеров или меню).
* `exists_text(name)` — проверить, существует ли на экране текст с таким именем.
* `play_sound(path)` — воспроизвести аудиофайл по указанному пути. Звук автоматически кэшируется в оперативной памяти при первом вызове, поэтому повторные выстрелы/взрывы работают мгновенно и без лагов.
* `random_range(min, max)` — получить случайное целое число в заданном диапазоне.

## 💻 Особенности встроенного языка программирования

Основной синтаксис скриптов полностью взят из **Python**, однако виртуальная машина накладывает несколько важных архитектурных ограничений:

⚠️ **Ограничения парсера:**
1. **Многострочные конструкции:** В текущей версии движка нельзя писать многострочные блоки `elif`, `for` и `while`. 
2. **Условные операторы:** Конструкции `if` и `else` поддерживают вложенность и работают абсолютно корректно благодаря кастомному стеку отступов.

📂 **Разделение логики по файлам:**
* **`code/init.txt`** — код из этого файла срабатывает строго один раз при запуске игры или при вызове команды `restart()`. Здесь создаются стартовые объекты, настраиваются начальные цвета и позиции.
* **`code/loop.txt`** — этот код автоматически выполняется построчно каждый кадр (в бесконечном цикле) сразу после того, как отработает `init.txt`.

---

## 🪐 Физический движок (Кастомная физика твердых тел)

В виртуальной машине реализована уникальная логика взаимодействия типов объектов:

1. **Dynamic ↔ Static:** Объекты типа `dynamic` соприкасаются со `static` объектами. Они не могут пройти друг сквозь друга. Если `static` объект (например, платформа) двигается кодом с помощью команды `move()`, он физически толкает на своем пути и увлекает за собой `dynamic` объекты.
2. **Static ↔ Static:** Объекты типа `static` абсолютно неосязаемы друг для друга. Они могут беспрепятственно проходить насквозь через другие `static` объекты.

## 🎮 Шаблон простейшей игры «Тир»

1. Убедитесь, что код игры уже написан и находится в папках `code/init.txt` и `code/loop.txt`.
2. Запустите главный файл движка:
   ```bash
   python main.py
   ```
3. В открывшейся консоли введите команду запуска окна, указав ширину и высоту через пробел:
   ```text
   start 500 500
   ```
   *Примечание: Базовая игра «Тир» создавалась и балансировалась строго под разрешение **500 на 500** пикселей.*
